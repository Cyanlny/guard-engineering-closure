# Decision Loop

## Bind identities and horizon

**Closure identity** = requested outcome + authority lineage + protected boundary + terminal validator + stop point.

**Decision key** = closure identity + generation + effect frontier + trust context. Scopes reuse/retry/V9 without new lineage.

Bound horizon at causal/authority/trust breaks. Use attributable, recomputable native logs/V9 lineage/cited evidence—not a global ledger. Campaign/tranche/P0–S3 are compatibility-only.

## Classify mode before result

Mode classifies legal route/control; formal result classifies current legal action, not downstream terminal permission. Rejected alternatives, labels/status, blocker severity, and result names do not set mode.

- `LIGHT`: local, reversible, low-impact, authorized; no Guard state/reference.
- `STANDARD`: material with consistent/bounded authority, lineage, budget, writers and boundaries; any result may apply.
- `RESCUE`: actual control loss—two no-progress cycles, corrected same-generation recurrence, conflicts that make evidence/authority/writer/lineage unbounded or remain irreconcilable after one discriminating observation, post-budget execution/accounting, or occurred history/counter/boundary bypass.

An attributable contained conflict stays STANDARD when mutation is frozen and one bounded read can select the route; conflict wording alone is not control loss. Intact blockers, foreign-predecessor rejection, proved authority breaks, and terminal native budgets stay STANDARD. Proposed bypass/wait is not loss; RESCUE freezes mutation/expensive starts.

## Attribute and arbitrate

Tag decisive claims: observed/reproducible `EVIDENCE`; authority-sourced `PROJECT_ASSERTION`; invalidatable `ASSUMPTION`; route-changing `UNKNOWN`; permission/ownership `AUTHORITY`, not access. Bind identity/time.

Distinguish symptom, direct cause, and evidenced root; state the deepest supported level without guessing. A decisive unknown needs the cheapest authorized discriminating observation; if none is safe and bounded, STOP with the missing condition. Bind repair to causal evidence, minimal authorized delta, retained valid results, predicted change, and affected real-path verification. State the actionable alternative and no-action consequence. Accounting UNKNOWN does not excuse diagnosis; irrelevant historical cost uncertainty does not justify expensive reruns. Apply existing same-root recurrence limits, not new checker/successor labels.

| Condition | Result |
|---|---|
| Unneeded, terminal, or no bounded authorized route | `STOP_NO_JUSTIFIED_ACTION` |
| One in-envelope route-changing unknown | `BOUNDED_DIAGNOSTIC_REQUIRED` |
| Known finite closure/compatibility/frontier/authority-envelope change; authority identifiable | `CONTROLLED_REBASE_REQUIRED` |
| Necessary, authorized, wholly in-envelope, bounded, predicted, verifiable | `ACTION_JUSTIFIED` |

At the stated decision point, a necessary, authorized native review or evidence application still owed to a commission, acceptance requirement, or direct consumer can be ACTION with reusable proof. Reading, relabeling, replying, or repeating completed review creates no obligation. When reuse applicability and entrusted duties are satisfied with no necessary action left, STOP means finished, not project failure.

A sole observation that selects the current route is DIAGNOSTIC. A fully specified, authorized proof or machine check executes an already chosen in-envelope route, even when its verdict gates a later action; it grants no terminal permission. Stable work: STOP + `wait=ACTIVE_OPERATION`; observe only when due. Rebase changes closure identity, compatibility, effect frontier, authority/envelope, or equivalent boundary contract; unknown/unbounded authority or boundary means stop. Unknown writers allow one decisive read or stop. Freeze mutation through diagnosis/rebase. Rebase uses `wait=NONE`; only named pending requests use `wait=AUTHORITY`. Wait is no result.

## Apply the surgical closure gate

Before build or costly execution, bind real inputs, necessary computation, authoritative results, direct consumers, authority, and stop in the existing plan/Card. Audit relevant scientific assumptions, samples/splits, randomness, numerical representation, code/dependencies, critical path, and resources. This broadens Observation only; select the scope-owned Mutation slice after discovery: proven cause, necessary consumers, unavoidable dependencies. Other risks are constraints, diagnostics/evidence, deferrals, or separate closures—not implementation tasks. Authority gaps are not subject defects.

Compare whole-path compute/read/parse/copy/transfer/storage/validation/recovery cost using native sizes, cardinalities, dependencies, and run evidence; mark unknowns. Choose the lowest expected total-cost authorized route sufficient for unchanged science/acceptance. Precedence: `no action/exact reuse → native mechanism → surgical correction + direct-consumer validation → dependent rebuild/reseal/revalidation → finite authority adjustment → structural replacement or stop if earlier routes are insufficient`. This is selection, not chronology: every effect needs prior authority; dependent closure work does not expand the causal mutation.

Necessary deliverables—reports, scientific results, or authorized project instructions—are judged by outcome, consumer, quantity, and authority, not native-mechanism insufficiency. Only new control mechanisms (checkers, owners, state/control layers, replacement frameworks) require all three: proven cause/necessary consumer, insufficient native mechanism, and a changed acceptance predicate. Otherwise defer or stop the added mechanism as control-surface churn; do not block a justified native delivery.

## Project the next boundary, not a state machine

For material work, temporarily project: project policy → read-only discovery → safe preparation → protected authorization when applicable → final assembly → terminal admission → project acceptance. It is neither state nor native lifecycle. At each boundary ask: legal action, authorizing capability, admission evidence. Skip absent phases; ACTION grants no later permission.

## Keep one six-line Closure Card

Use only in `STANDARD`/`RESCUE`; cite large native evidence by identity:

```text
TARGET — identity; acceptance; non-goals
STATE — decision key; mode; authority/concurrency; surfaces
EVIDENCE — sources; unknown; validator; horizon/recurrence
DECISION — causes; route; result
ACTION — envelope; prediction/falsifier; budget; validation
DELTA — local/structural progress; invalidation; wait; next/stop
```

Keep one logical operation plan, immutable raw-observation index, typed acceptance index, and Card. They may be native records, not files; indexes have no authority and keep validation, terminal-admission, and project-acceptance seals distinct.

## Count cycles and accounting

A material cycle is action, diagnosis, or validation. Progress closes an item/unknown, changes route, verifies canonical replacement, or advances the real validation/terminal/acceptance path. Gate-defined control-surface churn is not progress; count its cost. A recurrence assessment supplies its own key, horizon, and structural-progress evidence. Wait is no cycle; record `wait=AUTHORITY|RESOURCE|ACTIVE_OPERATION|NONE`. Shards share cycle/budget. Retry requires causal change and a different prediction.

For multi-cycle `STANDARD`/`RESCUE` or costly/external/migration/cutover/recurrence/rebase/audit/handoff, derive a read-only **Closure Accounting Summary** from native logs/V9/cited evidence. It is never LIGHT, authority, or state. Record window, sources/unknowns, actions, validation, blocks/waits/retries/rebase, recurrence, outcome.

Bind counts to event/source/window; unreconstructable=`UNKNOWN`. Classify once: pending=`WAIT`; unstarted/not pending=`BLOCK`; validator cannot start=`UNAVAILABLE`; started/no verdict=`VALIDATOR_DEFECT`; executed negative=`FAIL`; material delta=`CHANGE`. Wait is not failure/no-progress.

Once per exact native review/evidence identity, an authorized, read-only retrospective may run only if it can change a later route or handoff; otherwise reuse or stop. Cite accounting; proposals need separate authority and may target only direct consumers or future Guard work.
